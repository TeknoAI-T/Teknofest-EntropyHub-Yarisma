03

PYTHON API

Günlük kullanım için sade arayüz.

EntropyHub(dt=0.01)

OS entropisiyle yeni bir örnek oluşturur. dt, RK4 zaman adımıdır.

constructor
random_bytes(n, iterations=1)

n adet byte döndürür. Daha yüksek iteration, örnekler arasında daha fazla faz uzayı mesafesi sağlar.

bytes
random_int(lo, hi)

Rejection sampling kullanarak kapalı aralıkta (lo ≤ x ≤ hi) uniform tamsayı üretir.

integer
random_float()

[0, 1) aralığında 64 bitlik ham çıktıyı ölçekleyerek uniform kayan nokta üretir.

float
verify_chaos(...)

Canlı örneği bozmadan Benettin yöntemiyle en büyük Lyapunov üssünü tahmin eder.

diagnostic
reseed() · state

Yeni OS entropisiyle tohumlar veya mevcut (x, y, z) konumunu okur.

state
Python
from entropyhub import EntropyHub

hub = EntropyHub()

print(hub.random_bytes(16))
print(hub.random_int(1, 6))       # zar atışı
print(hub.random_float())         # [0, 1)
print(hub.state)                  # (x, y, z)

lambda_max = hub.verify_chaos()
print(f"Lyapunov exponent: {lambda_max:.5f}")

hub.reseed()                      # yeni OS entropisi
